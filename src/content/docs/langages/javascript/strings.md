## Template literal

```js
const nom = "Ada";
`Bonjour ${nom}`; // "Bonjour Ada"
```

`.length`, `.toUpperCase()`, `.toLowerCase()`, `.trim()`, `.split()`, `.includes()`, `.indexOf()`, `.slice()`, `.replace()`
