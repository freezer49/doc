sidebar:
  order: 5
---

```js
const obj = { nom: "Ada", age: 25 };
```

- **Accès** → `obj.nom` ou `obj["nom"]`
- **Ajouter** → `obj.ville = "Nantes"`
- **Supprimer** → `delete obj.age`

## Méthodes utiles

- **`Object.keys(obj)`** → tableau des clés
- **`Object.values(obj)`** → tableau des valeurs
