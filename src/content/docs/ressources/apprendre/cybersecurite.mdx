## En un coup d'œil

| Plateforme | Pour quoi | Prix |
| --- | --- | --- |
| TryHackMe | débuter, parcours guidés (cours + box) | 14 €/mois |
| Root Me | petits challenges, thématiques variées | gratuit |
| Hackropole | challenges du FCSC (ANSSI) | gratuit |
| CryptoHack | cryptographie | gratuit |
| Hacker101 | sécurité web, CTF (HackerOne) | gratuit |
| PentesterLab | sécurité web | payant |
| Hack The Box | machines vulnérables, académie, certifications | 8 $/mois (débutant) |
| YesWeHack | bug bounty | — |

:::note
Les tarifs sont indicatifs, ceux relevés au moment de l'écriture.
:::
