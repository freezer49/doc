title: Raccourcis clavier
description: Raccourcis Mac pour les caractères spéciaux, VS Code et le navigateur.
---

Raccourcis pour **Mac, clavier AZERTY**. `⌘` = Cmd, `⌥` = Option (Alt), `⌃` = Control, `⇧` = Maj.

## Caractères spéciaux

| Caractère | Raccourci |
| --- | --- |
| `~` tilde | `⌥ N` (puis `Espace` si rien n'apparaît) |
| `{` `}` accolades | `⌥ (` et `⌥ )` |
| `[` `]` crochets | `⌥ ⇧ (` et `⌥ ⇧ )` |
| `\|` barre verticale | `⌥ ⇧ L` |
| `\` antislash | `⌥ ⇧ :` |

## VS Code

| Action | Raccourci |
| --- | --- |
| Commenter / décommenter | `⌘ /` |
| Sélectionner l'occurrence suivante (multi-curseur) | `⌘ D` (répéter pour chaque occurrence) |
| Rechercher dans le fichier | `⌘ F` |
| Rechercher et remplacer | `⌃ H` (par défaut sur Mac : `⌥ ⌘ F`) |
| Afficher les suggestions (dont les imports automatiques) | `⌃ Espace` |
| Ouvrir un fichier par son nom | `⌘ P` |
| Palette de commandes | `⌘ ⇧ P` |
| Déplacer la ligne | `⌥ ↑` / `⌥ ↓` |
| Dupliquer la ligne | `⌥ ⇧ ↓` |
| Formater le fichier | `⌥ ⇧ F` |

## Navigateur

| Action | Raccourci |
| --- | --- |
| Rafraîchir la page | `⌘ R` |
| Rafraîchir sans cache | `⌘ ⇧ R` |
| Ouvrir les outils de développement | `⌥ ⌘ I` |
