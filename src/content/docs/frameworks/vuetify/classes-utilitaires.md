| Préfixe | Rôle | Exemples |
|---|---|---|
| `pa-`, `px-`, `pt-`… | Padding | `pa-6`, `px-md-16` |
| `ma-`, `mt-`, `mb-`… | Marge | `mt-3`, `mb-0` |
| `d-` | Affichage | `d-flex`, `d-none`, `d-md-block` |
| `flex-` | Direction, retour | `flex-column`, `flex-wrap` |
| `align-`, `justify-` | Alignement flex | `align-center`, `justify-space-between` |
| `ga-` | Espacement entre enfants flex (gap) | `ga-3` |
| `text-` | Taille, style, couleur | `text-h5`, `text-body-1`, `text-medium-emphasis` |
| `font-weight-` | Graisse | `font-weight-bold` |

Une échelle de 0 à 16 (`1` = 4 px, `6` = 24 px, `16` = 64 px) régit les espacements.
