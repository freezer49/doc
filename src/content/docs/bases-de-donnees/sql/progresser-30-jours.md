## Jours 1 à 5 : les fondamentaux

- Explorer la syntaxe de base
- Pratiquer les requêtes simples (`SELECT`, `WHERE`, `ORDER BY`)
- Se familiariser avec les fonctions d'agrégation (`COUNT`, `SUM`, `AVG`)

→ voir [Requêtes essentielles](../requetes/)

## Jours 6 à 10 : requêtes avancées

- Maîtriser les différents types de `JOIN`
- Approfondir les sous-requêtes
- Explorer `GROUP BY` et `HAVING`
- Entraînement : le cours « Intermediate SQL » de DataCamp

## Jours 11 à 15 : pratique intensive

- Mettre ces concepts en pratique sur LeetCode ou DataLemur
- Résoudre des problèmes de difficulté variée

## Jours 16 à 20 : optimisation

- Comprendre l'ordre d'exécution des clauses SQL
- Analyser les plans d'exécution (`EXPLAIN`)
- Optimiser ses requêtes pour de meilleures performances
- Exercice : comparer l'efficacité de plusieurs approches pour une même requête

## Jours 21 à 25 : fonctions de fenêtrage

- Explorer `ROW_NUMBER`, `RANK`, `DENSE_RANK`
- Maîtriser `LAG` / `LEAD` pour l'analyse temporelle
- Utiliser `PARTITION BY` pour des calculs segmentés
- Défi : créer un classement des ventes par catégorie et par mois

## Jours 26 à 28 : projets concrets

- Analyser un jeu de données Kaggle avec SQL
- Créer un tableau de bord de KPI pour une entreprise fictive
- Nettoyer et transformer un jeu de données complexe

## Jours 29 et 30 : consolidation

- Réviser les concepts clés
- Identifier ses points forts et ses axes d'amélioration
- Planifier la suite de l'apprentissage

:::tip[Bonus : le portfolio]
- Documenter ses projets sur GitHub
- Rédiger des articles techniques (Medium, LinkedIn)
- Créer une GitHub Page avec son portfolio
:::
